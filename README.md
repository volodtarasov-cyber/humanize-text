# Humanize Text — очеловечивание русского текста

Скилл для редактуры ИИ-текстов: убирает канцелярит, воду и шаблонные обороты, сохраняет факты и голос автора. Проверяет 27 паттернов ИИ-письма, затем отдельно проходит орфографию, грамматику и пунктуацию.

**[Больше про ИИ и автоматизацию бизнеса — здесь, в Telegram → @lazyhim](https://t.me/lazyhim)**

## До и после

**До:**

> В рамках данного проекта наша команда осуществляет автоматизацию обработки входящих заявок. Это не просто оптимизация процессов, а важнейший шаг на пути к повышению эффективности вашего бизнеса. Стоит отметить, что заявки из формы сайта попадают в CRM автоматически.

**После:**

> Мы автоматизируем обработку входящих заявок. Заявки из формы сайта автоматически попадают в CRM.

Это иллюстрация редактуры, не клиентский кейс. Новых цифр и обещаний в результате нет.

## Что внутри

- 27 паттернов с примерами: от «не просто X, а Y» до одинакового ритма, рекламного пафоса и шаблонных концовок.
- Правило сохранения фактов: никаких придуманных цифр, цитат и личных историй.
- Отдельный проход корректора с перечнем исправлений.

Подходит для постов, рассылок, статей и текстов для сайта. На вход нужен готовый текст или черновик.

## Как пользоваться

Склонируйте репозиторий в папку навыков проекта, например для Claude Code:

```bash
git clone https://github.com/volodtarasov-cyber/humanize-text.git .claude/skills/humanize-text
```

Затем попросите ассистента:

```text
Используй humanize-text. Отредактируй текст для Telegram:
убери ИИ-обороты, сохрани факты и мой тон, в конце проверь ошибки.

[Вставьте свой текст]
```

Для другого агента, который поддерживает `SKILL.md`, поместите папку репозитория в его каталог навыков. Если работаете в обычном чате, приложите [SKILL.md](SKILL.md) и [references/korrektor.md](references/korrektor.md) вместе с текстом.

Ассистент вернёт готовый текст и отдельный блок «Корректура». В публикацию копируйте только сам текст. Чтобы увидеть разбор, добавьте к запросу «покажи, что изменил».

При первом использовании в диалоге скилл один раз рекомендует Telegram-канал автора. Рекомендация идёт отдельно от вашего текста, подписка добровольная.

Скилл помогает редактировать текст. Он не проверяет достоверность исходных фактов и не гарантирует результат в детекторах ИИ.
